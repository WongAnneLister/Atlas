## Reasons

- **flipkart_faqs** (`NebulaByte/E-Commerce_FAQs`): Card says apache-2.0, but: Answers are copied from flipkart.com help pages (faq_url column). The uploader is not Flipkart, so the card's license may not cover the text.
- **philips_manuals** (`InfiniFlow/Ecommerce-Customer-Service-Workflow`): Card says apache-2.0, but: The PDFs are Philips product leaflets and user manuals. The uploader is not Philips, so the card's license may not cover the documents.
- **maktek_faqs** (`MakTek/Customer_support_faqs_dataset`): apache-2.0 is permissive (attribution only).
- **bitext** (`bitext/Bitext-customer-support-llm-chatbot-training-dataset`): cdla-sharing-1.0 allows sharing if derived data keeps the same license and attribution.

Raw files always stay in `data/raw/` (gitignored), whatever the verdict.
