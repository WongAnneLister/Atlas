# 13 — Answerable store controls

**What**
I wrote 40 questions that name one store and do have an answer. Each topic also has many similar documents in the other store. I froze them before testing the store filter on them.

**Why**
My cross-store test only had questions with no answer. It could show fewer wrong answers, but not extra handoffs. A filter can also hide the right page by mistake.

**Number**
The build report lists 40 frozen items, 20 for each store. I have not measured the bot on them yet.
Source: eval/reports/store_controls.md

**Trade-off**
I paraphrased the questions myself, so they may be easier than real chats. Each answer comes from one source answer. A human still needs to review them.

**Likely follow-up question**
Q: Why pick topics both stores cover?
A: Those are the hard cases for the filter. The other store's pages rank high there. If the filter hurts anywhere, it hurts there first.
