## Interpretation and limits

Intent accuracy misses the configured 90% target; results are unchanged.
A correct path still may contain the wrong action; path accuracy is not task success.
Product extras come only from retrieval dev questions, not its test split.
Return extras were model-drafted; greetings were authored separately.
The classifier and return drafter share a provider, limiting independence.
Normalized exact duplicates are excluded; near-paraphrases can cross the Bitext partition.
Source balancing changes the natural intent distribution, so accuracy is benchmark-specific.
Mapped Bitext labels sometimes hide ambiguity between general rules and individual actions.
Unsupported account/review requests use the fixed path under this project's declared scope.
All five graph paths are stubs; this measures classification, not answers or refusal safety.
The provider alias and response model names do not pin immutable model weights.
